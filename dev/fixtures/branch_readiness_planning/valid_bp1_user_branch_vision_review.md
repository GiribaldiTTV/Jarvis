## Codex Understanding

## End-State Vision

The end state is a coherent feature path where the user sees the current state, opens the relevant control surface, and understands which behavior is future-gated.

## What Will I Actually See, And Where Will I See It?

The USER will see a Dashboard card, a compact standalone window when opened, and clear status copy that distinguishes current behavior from future work.

## How It Will Function

The Dashboard card launches the compact surface, the compact surface summarizes the active target, and advanced details remain behind a later settings surface.

## User Experience Flow

The user opens the Dashboard, checks the card status, opens the compact surface, reviews the summary, and closes or minimizes the window without losing context.

## Surface Map

Dashboard card owns launch and preview, compact window owns focused control, settings window owns later advanced options, and durable logs remain a future viewer surface.

## Product Options / Design Paths

Option A keeps preview first, Option B opens the compact surface first, and Option C defers both until runtime execution exists.

  Surface: Dashboard card plus compact window.
  Flow: USER sees status first, then opens controls.
  Tradeoff: slower to reach future controls but clearer before execution exists.
  Risk: the preview could feel passive without strong status copy.
